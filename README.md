ECHODEEP is an original sonar-cave game: the cave is pitch black and only your sound reveals it — every ping lights the walls, the shards and the predators, and every ping calls the listeners to your last sound. Move with WASD, ping with Space or click, collect all resonance shards, and reach the exit before the dark catches you. 3 levels, 3 lives, echo meter, synthesized sound.

## Run it

```sh
python3 -m http.server 8123 --directory game
```

Then open http://localhost:8123/ in a desktop browser. No build step, no network requests — the game is static files under game/.
